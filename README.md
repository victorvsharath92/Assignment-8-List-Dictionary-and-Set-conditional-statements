This python assignment covers practical exercises involving lists, dictionaries, sets, and conditional statements.

List Tasks (Creation, Modification, and Access)
Covers creating integer and string lists, performing actions like append, insert, remove, pop, extend, sort, max, min and sum.
Includes indexing and slicing tasks to retrieve elements by position or in reverse order.

Dictionary Tasks (Creation, Modification, and Access)
Tasks involve creating a student marks mapping, retrieving individual scores, adding new key-value pairs, and updating existing entries.
Requests the output of dictionary contents using the keys(), values(), and items() methods.

Set Operations and Analysis
Demonstrates unique element behavior and immutability by testing set creation with duplicate values and item assignment.
Requires calculating the union and intersection between two integer sets.

Operators & Conditional Statements Program1
Outlines a performance category script that prompts users for a score between 0 and 10.
Evaluates scores using conditional logic (IF, ELIF, ELSE)
